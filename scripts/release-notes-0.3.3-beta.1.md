## What's included

- Adds Grok reasoning effort controls when creating or configuring agents
- Preserves standard ACP thinking writes while applying Grok-specific model settings
- Includes Paseo v0.3.2 as the release base

## Downloads

- **Windows:** use the x64 or ARM64 `Paseo-Setup` installer
- **Android:** sideload `paseo-v0.3.3-beta.1-android.apk`; its package name remains `sh.paseo`
- **Linux or Windows daemon:** download the npm bundle for your archive format and run its installer with Node.js 22

## Notes

- The Android release APK is signed in GitHub Actions with a generated Android key and may require uninstalling a differently signed `sh.paseo` build first
- The npm bundle installs six matching Paseo workspace packages and downloads third-party dependencies from the configured npm registry
- This fork release uses the `xnqycs` desktop update feed instead of the upstream stable feed
